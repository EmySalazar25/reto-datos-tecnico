# Material del reto

Documentación que acompaña al reto, sin cambios: requerimiento del negocio, diccionario de la
capa landing, contrato de los marts y convenciones de capas. Se conserva tal cual porque es el
insumo que el agente usa como contexto, igual que lo haría una persona del equipo.

Los datos de `data/replica/` son ficticios: se generaron para el reto y no corresponden a
clientes, operaciones ni cifras reales.
